# 30天情侣计划 · 第一期

Perth视角轻喜剧互动故事。本仓库当前仅发布 **D1—D7**。

- 7天、6个选择节点、22个选项。
- D7结束显示“本期已完”，保留进度，不进入后续剧情或结局。
- 支持自动/手动存档、JSON导入导出，以及在设置中主动下载本期供离线游玩。
- 当前无音乐、无配音。人物私生活、事件、对白均为本作虚构。

## 运行与部署

这是可直接部署的静态网站，根目录为index.html，运行时无需安装依赖或执行构建。

本地预览可在仓库目录使用Python 3运行 `python -m http.server 4187`，然后打开 http://127.0.0.1:4187/ 。请勿直接双击index.html。

Cloudflare Pages可使用本仓库根目录作为静态发布目录。正式网站使用HTTPS；后续更新沿用同一网址，以便继续读取浏览器进度。

## 进度与更新

手机消息以聊天窗逐条显示。旁白与对白使用不同样式，长段落按屏幕尺寸和字号分页，存档保留当前阅读位置。

建议横屏游玩，长期使用同一浏览器。清理网站数据、换浏览器或换网址可能需要导出/导入进度。导出文件只包含当前进度，不是全部手动存档库的备份。

翻页时复用未变化的背景与人物图片，预加载邻近场景，并合并同次操作的同步存档写入，以减少场景切换停顿。

新版本会在联网打开、回到页面或恢复联网时自动检查，前台联网时每60秒检查一次。更新前保留进度，更新后自动接回已开放段落，无需手动更新。离线资源应等待下载成功后再断网。

D8起的剧情正在修订。已玩到D8—D12的存档会停在本期结束页，保存或导出时保留原段落和选项。后续若调整剧情结构，将在重新开放前核对存档迁移。
